## 1. 住所管理機能の追加

### 1.1 マイページ住所管理

- `appfew/statics/js/address-manage.js`

**新規ファイル**:
- `appfew/templates/sell_address_manage.html`
- `appfew/statics/js/sell-address-manage.js`

**機能**:

**新規ファイル**: `appfew/templates/mypage/_sidebar.html`

マイページのサイドバーを共通テンプレートに分離し、住所管理リンクを追加。

## 4. 非公開商品のアクセス修正

**ファイル**: `appfew/monotal/views.py` (ProductDetailView)

**修正前**:
```python
# 削除商品（status_id=4）へのアクセスを拒否
if product.product_status_id == 4:
    messages.error(request, 'この商品は削除されました。')
    return redirect('product_list')
```

**修正後**:
```python
# 非公開商品（status_id=4）は出品者のみアクセス可能
if product.product_status_id == 4:
    if not request.user.is_authenticated or request.user != product.user:
        messages.error(request, 'この商品は非公開です。')
        return redirect('product_list')
```
