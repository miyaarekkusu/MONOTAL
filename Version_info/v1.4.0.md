# Version 1.4.0 - マイページ機能追加

**リリース日**: 2026-01-20

---

## 概要

マイページ機能の実装。プロフィールページの改善、フォロー機能、閲覧履歴、ブックマーク一覧、出品一覧を追加。

---

## 追加機能

### 1. プロフィールページの改善

| 項目 | 内容 |
|------|------|
| タブ切り替え | 出品リスト / ブックマーク（本人のみ）の切り替え |
| 本人確認ステータス | 承認/審査中/却下/未申請の状態表示 |
| フォロー情報 | フォロワー数、フォロー中数の表示 |
| フォローボタン | 他ユーザープロフィール閲覧時にフォロー/アンフォロー |

### 2. フォロー機能

| 項目 | 内容 |
|------|------|
| API | `POST /monotal/user/<id>/follow/` |
| 動作 | トグル方式（フォロー/アンフォロー切り替え） |
| レスポンス | `{ success, is_following, follower_count }` |
| 制限 | 自分自身はフォロー不可 |

### 3. ヘッダードロップダウンメニュー

プロフィール画像クリックで表示されるメニュー:
- マイページ
- プロフィール
- フォローリスト
- ログアウト

### 4. マイページ

| ページ | URL | 内容 |
|--------|-----|------|
| 閲覧履歴 | `/monotal/mypage/browsing-history/` | 閲覧した商品一覧（最新順） |
| ブックマーク一覧 | `/monotal/mypage/bookmark-list/` | ブックマークした商品一覧 |
| フォローリスト | `/monotal/mypage/follow-list/` | フォロー中のユーザー一覧 |
| 出品一覧 | `/monotal/mypage/listing/` | 自分が出品した商品一覧 |

### 5. 閲覧履歴記録

| 項目 | 内容 |
|------|------|
| 対象 | ログインユーザーのみ |
| 除外 | 自分の出品商品は記録しない |
| 動作 | 同一商品の閲覧履歴は削除して再作成（最新日時に更新） |
| 記録タイミング | ProductDetailView（商品詳細ページ）閲覧時 |

## 本人確認ステータス表示

| ステータス | アバターバッジ | テキストバッジ |
|-----------|--------------|---------------|
| 1（承認） | 緑チェック | 「本人確認済」（緑） |
| 0（審査中） | 黄色時計 | 「審査中」（黄色） |
| 2（却下） | 赤×印 | 「再申請が必要」（赤、リンク付き） |
| 未申請 | 表示なし | 本人→「本人確認する」/ 他者→「未確認」 |

## 追加ビュー（views.py）

| クラス | 用途 |
|--------|------|
| `FollowToggleView` | フォロー/アンフォローAPI |
| `MyPageFollowListView` | フォローリスト表示 |
| `MyPageBookmarkListView` | ブックマーク一覧表示 |
| `MyPageBrowsingHistoryView` | 閲覧履歴表示 |
| `MyPageListingView` | 出品一覧表示 |

### ProfileViewの変更

コンテキストに以下を追加:

| 変数 | 内容 |
|------|------|
| `follower_count` | フォロワー数 |
| `following_count` | フォロー中数 |
| `is_following` | ログインユーザーがフォロー中か |
| `identity_status` | 本人確認ステータス |
| `bookmarked_products` | ブックマーク商品（本人のみ） |
| `bookmarks_count` | ブックマーク数 |
