### テンプレート・CSS・JS の対応関係

各画面はテンプレート、CSS、JSの3つのファイルで構成されます。

| 画面 | テンプレート | CSS | JS |
|------|-------------|-----|-----|
| プロフィール設定 | profile_setting.html | profile_setting.css | profile_setting.js |
| 商品出品 | create_sell.html | create-sell.css | create-sell.js |
| 本人確認申請 | identity_verification.html | identity_verification.css | identity_verification.js |
| 管理者：審査一覧 | admin/verification_list.html | admin_verification.css | - |
| 管理者：審査詳細 | admin/verification_detail.html | admin_verification.css | admin_verification.js |

### テンプレートでのCSS/JS参照方法

```html
{% extends 'base.html' %}
{% load static %}

{% block extra_css %}
<link rel="stylesheet" type="text/css" href="{% static 'css/画面名.css' %}">
{% endblock %}

{% block content %}
<!-- 画面内容 -->
{% endblock %}

{% block extra_js %}
<script src="{% static 'js/画面名.js' %}"></script>
{% endblock %}
```

**ポイント**:
- `{% load static %}` でstaticタグを有効化
- `{% static 'パス' %}` で静的ファイルのURLを生成
- CSSは `extra_css` ブロック、JSは `extra_js` ブロックに配置
- base.htmlを継承することで共通のヘッダー・フッターを利用

## 認証方式

### ログイン
- **識別子**: 電話番号
- **認証**: パスワード
- **バックエンド**: `PhonePasswordBackend`

### ユーザー登録フロー
1. フォーム入力 or Google OAuth
2. EmailVerificationToken作成（24時間有効）
3. 認証メール送信
4. リンククリック → ユーザー作成
5. 自動ログイン

---

## API/通信パターン

### リクエスト
- **形式**: AJAX + FormData
- **識別ヘッダ**: `X-Requested-With: XMLHttpRequest`
- **CSRF**: `X-CSRFToken`必須

### レスポンス（JSON）
```javascript
// 成功
{
    "success": true,
    "message": "処理完了",
    "data": {...},
    "redirect_url": "/path/"
}

// エラー
{
    "success": false,
    "errors": {
        "field_name": "エラーメッセージ"
    }
}
```
