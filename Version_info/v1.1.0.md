# Version 1.1.0 - 本人確認機能追加

**リリース日**: 2026-01-15

---

## 概要

本人確認申請機能（ユーザー向け）と審査機能（管理者向け）を追加。

---

## 追加機能

### 1. 本人確認申請（ユーザー向け）

| 項目 | 内容 |
|------|------|
| URL | `/monotal/identity-verification/` |
| 機能 | 顔写真と身分証の2枚をアップロードして本人確認を申請 |
| ステータス表示 | 審査中、承認済み、却下の状態を表示 |

### 2. 本人確認審査（管理者向け）

| 項目 | 内容 |
|------|------|
| 一覧URL | `/monotal/admin/verifications/` |
| 詳細URL | `/monotal/admin/verifications/<id>/` |
| 機能 | 未審査の申請を古い順に表示、画像確認、承認/却下 |
| 権限 | `is_staff=True` のユーザーのみアクセス可 |

## ステータス定義

### IdentityVerificationStatus

| ID | 名称 | 説明 |
|----|------|------|
| 0 | 未確認 | 申請後、審査待ち |
| 1 | 承認 | 管理者が承認 |
| 2 | 却下 | 管理者が却下 |

### 承認時の動作

- `IdentityVerification.identity_verification_status_id` → 1
- `IdentityVerification.approval_datetime` → 現在日時
- `User.user_status_id` → 2（承認済みユーザー）

---

## 画像アップロード仕様

| 項目 | 値 |
|------|-----|
| 枚数 | 2枚固定（顔写真 + 身分証） |
| サイズ上限 | 5MB/枚 |
| 形式 | image/* |
| 保存形式 | BinaryField（DB直接保存） |
