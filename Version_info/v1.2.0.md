# Version 1.2.0 - 商品詳細ページの刷新

**リリース日**: 2026-01-20

---

## 概要

商品詳細ページのデザイン刷新と機能追加。閲覧履歴、ブックマーク、コメント機能を実装。

---

## 追加機能

### 1. 閲覧履歴（BrowsingHistory）

| 項目 | 内容 |
|------|------|
| 対象 | ログインユーザーのみ |
| 除外 | 自分の出品商品は記録しない |
| 動作 | 同一商品の閲覧履歴は削除して再作成（最新日時に更新） |

### 2. ブックマーク（お気に入り）機能

| 項目 | 内容 |
|------|------|
| API | `POST /monotal/product/<id>/bookmark/` |
| 動作 | トグル方式（追加/削除を切り替え） |
| レスポンス | `{ success, is_bookmarked, bookmark_count }` |

### 3. コメント機能

| 項目 | 内容 |
|------|------|
| 取得API | `GET /monotal/product/<id>/messages/` |
| 送信API | `POST /monotal/product/<id>/messages/` |
| 削除API | `DELETE /monotal/product/<id>/messages/<message_id>/delete/` |
| 削除権限 | 出品者のみ |

### 4. レンタルプラン選択

| 項目 | 内容 |
|------|------|
| データソース | ProductRentalPlanテーブルから動的取得 |
| 表示 | 日数と料金のボタン選択式 |
| 備考 | 開始日・終了日は個人取引画面で設定（ここでは選択のみ） |

## UI/UX改善

### サイドバー固定表示

デスクトップ表示（1024px以上）で右サイドバーをスクロール追従（sticky）に変更。

```css
@media (min-width: 1024px) {
    .detail-right {
        position: sticky;
        top: 100px;
    }
}
```

### コメント削除ボタン

- 出品者のみ表示
- コメントホバー時にゴミ箱アイコン表示
- 確認ダイアログ後に削除実行

## 追加ビュー（views.py）

| クラス | 用途 |
|--------|------|
| `BookmarkToggleView` | ブックマークのトグルAPI |
| `ProductMessagesView` | コメント取得・送信API |
| `ProductMessageDeleteView` | コメント削除API（出品者専用） |

### ProductDetailViewの変更

コンテキストに以下を追加:

| 変数 | 内容 |
|------|------|
| `rental_plans` | ProductRentalPlanのクエリセット |
| `seller_address` | 出品者の住所（都道府県表示用） |
| `is_bookmarked` | ログインユーザーがブックマーク済みか |
| `bookmark_count` | ブックマーク総数 |
| `message_count` | コメント数 |
| `is_seller` | 現在のユーザーが出品者か |

## 技術的な注意点

### ChatRoom自動作成

商品登録時（CreateSellView）にChatRoomを自動作成するように変更済み。

```python
chat_room_type, _ = ChatRoomType.objects.get_or_create(
    chat_room_type_id=3,
    defaults={'type_name': '商品チャット'}
)
ChatRoom.objects.create(
    chat_room_type=chat_room_type,
    product=product
)
```

### コメント削除の権限チェック

```python
# 出品者かどうか確認
if request.user != product.user:
    return JsonResponse({
        'success': False,
        'error': 'コメントを削除する権限がありません'
    }, status=403)
```
