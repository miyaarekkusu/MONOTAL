# C2Cレンタルサービス リスク対策調査

## 調査日: 2026-02-06

## 課題

C2Cレンタルでは「商品が届いたのに届いていないと主張される」「返却されない」などのトラブルが発生するリスクがある。
特に追跡番号のない普通郵便などでは証拠が残らない。

---

## 既存サービスの対策

### 1. メルカリ・ラクマ（フリマ）

| 対策 | 詳細 |
|-----|------|
| エスクロー決済 | 購入者が受取確認するまで出品者に入金されない |
| 専用配送（追跡必須） | メルカリ便・かんたんラクマパックで追跡+補償 |
| 全額補償プログラム | 2025年7月〜 正規ユーザーへの補償拡大 |
| 回収センター | 2024年〜 疑わしい取引の商品を回収・目視確認 |
| 本人確認 | 高額取引時に必須化 |

### 2. Fat Llama（イギリスのC2Cレンタル）

| 対策 | 詳細 |
|-----|------|
| 高額保証 | UK £25,000 / US $30,000まで補償 |
| 手数料 | 貸主・借主双方から**15%**ずつ徴収（計30%） |
| 盗難補償 | プラットフォームが全額補償 |
| 本人確認 | ID確認必須 |
| 保険連携 | 借主の個人保険を先に適用、拒否された場合にプラットフォーム補償 |

### 3. アリススタイル / Quotta（日本のC2Cレンタル）

| 対策 | 詳細 |
|-----|------|
| 保険適用 | 破損は保険で修理・交換 |
| 盗難 | **補償対象外**だった（過去）→ トラブル報告あり |
| 本人確認強化 | 後から厳格化して安全性向上 |
| 運営仲介 | トラブル時に運営が介入 |

## 追跡可能な配送方法

| 発送方法 | 追跡 | 料金目安 |
|---------|-----|---------|
| 普通郵便（定形・定形外） | ✗ | 84円〜 |
| レターパック ライト/プラス | ✓ | 370円/520円 |

| 特定記録郵便 | ✓ | +160円 |
| ヤマト宅急便 | ✓ | サイズによる |
| ネコポス | ✓ | 法人契約 |

---

## 成功しているサービスの共通点

1. エスクロー決済（受取確認まで入金しない）
2. 追跡可能な配送を推奨/必須
3. 本人確認の徹底
4. 高めの手数料で補償原資を確保（15〜30%）
5. 盗難も含めた補償

---

## 結論

**リスクを0にすることは不可能**

目指すべきは「リスクを許容範囲に抑えつつ、利便性とコストのバランスを取る」こと。

```
被害額 < 手数料収入 × 一定割合
```

この式が成り立てばビジネスとして継続可能。
