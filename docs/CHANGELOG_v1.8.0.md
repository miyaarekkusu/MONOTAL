# CHANGELOG v1.8.0

## リリース日
2026-02-04

## 概要
レンタル管理機能の改善、出品フローの最適化、各種バグ修正

---

## 新機能・改善

### レンタル管理画面
- **タブ構成の変更**: 4タブ構成に変更
  - 承認待ち
  - 承認済み/完了
  - 拒否
  - キャンセル
- **削除商品の表示**: 商品が削除された場合、キャンセルタブに「削除」ステータスで表示
- **名称変更**: 「却下」を「拒否」に統一

### 出品機能
- **バリデーション強化**:
  - レンタル日数: 最大3650日
  - レンタル金額: 最大9,999,999円
- **UI改善**:
  - 商品画像の「*必須」バッジを削除
  - サブタイトルを「各項目を入力して出品を完了させてください」に変更
- **フォームデータ保存機能**: 住所編集画面から戻った際に入力値を復元
- **リダイレクト先変更**: 出品成功後、商品詳細ページへ遷移

### レンタル開始ページ
- **フォームデータ保存機能**: 住所・カード編集画面から戻った際に選択状態を復元

---

## バグ修正

### 商品ステータス定数の修正
- データベースの値に合わせて定数を修正:
  - `PRODUCT_STATUS_LISTED = 1` (貸出可能)
  - `PRODUCT_STATUS_RENTING = 2` (貸出中)
  - `PRODUCT_STATUS_PAUSED = 3` (非公開)
  - `PRODUCT_STATUS_DELETED = 4` (削除)

### 商品削除処理の修正
- `ProductDeleteView`で`product_status_id`を正しく設定するよう修正

### 出品ボタンが押せない問題の修正
- フロントエンドの不要な銀行口座バリデーションを削除

- 住所編集から戻った際は画像の再アップロードが必要です
