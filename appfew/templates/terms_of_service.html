本利用規約（以下「本規約」）は、MONOTAL（以下「本サービス」）の利用に関する条件を定めるものです。本サービスをご利用いただくにあたり、本規約に同意していただく必要があります。

第1条（総則）

  1. 本規約は、MONOTAL運営事務局（以下「運営者」）が提供するカメラ・ガジェット等のレンタルプラットフォームサービス「MONOTAL」の利用に関する一切の関係に適用されます。
  2. 運営者は、本規約のほかに、各種ガイドラインやポリシー（以下「個別規定」）を定めることがあります。個別規定は本規約の一部を構成するものとします。
  3. 本規約と個別規定が矛盾する場合は、個別規定が優先されるものとします。

第2条（定義）

本規約において使用する用語の定義は以下のとおりとします。

  1. 「ユーザー」とは、本サービスに会員登録を行ったすべての利用者をいいます。
  2. 「出品者」とは、本サービスにおいて商品をレンタル用として出品するユーザーをいいます。
  3. 「借り手」とは、本サービスにおいて商品のレンタルを申請するユーザーをいいます。
  4. 「商品」とは、出品者が本サービス上に出品したカメラ、ガジェットその他のレンタル対象物をいいます。
  5. 「取引」とは、借り手によるレンタル申請から商品の返却完了までの一連のプロセスをいいます。
  6. 「レンタル料金」とは、商品のレンタルに対して借り手が支払う料金をいいます。

第3条（会員登録）

  1. 本サービスの利用を希望する者は、運営者の定める方法により会員登録を行うものとします。
  2. 会員登録にはメールアドレスの認証が必要です。登録されたメールアドレス宛に認証メールが送信され、認証手続きを完了することで登録が完了します。
  3. ユーザーは1人につき1つのアカウントのみ保有できます。複数アカウントの作成は禁止されます。
  4. 満18歳未満の方は、保護者の同意を得た上で本サービスをご利用ください。
  5. 以下の場合、運営者は会員登録を拒否することがあります。
    • 登録内容に虚偽、誤記、または記載漏れがあった場合
    • 過去に本規約違反により利用停止となった者である場合
    • その他、運営者が会員登録を適当でないと判断した場合

第4条（本人確認）

  1. 商品の出品およびレンタル取引を行うためには、本人確認手続きを完了する必要があります。
  2. ユーザーは、運営者が指定する本人確認書類（運転免許証、マイナンバーカード等）を提出するものとします。
  3. 本人確認書類に虚偽の情報が含まれていた場合、運営者はアカウントの停止その他適切な措置を講じることができます。
  4. 運営者は、本人確認の審査結果について、理由を開示する義務を負わないものとします。

第5条（商品の出品）

  1. 出品者は、本人確認手続きを完了した上で、運営者の定める方法により商品を出品できます。
  2. 出品者は、商品の状態、仕様、付属品等について正確かつ詳細な説明を記載するものとします。
  3. 以下の商品の出品は禁止されます。
    • 法令に違反する商品または盗品
    • 第三者の権利を侵害する商品
    • 安全性に問題のある商品
    • 運営者が不適切と判断した商品
  4. 運営者は、出品された商品が本規約に違反すると判断した場合、事前の通知なく出品を削除できるものとします。

第6条（レンタル取引）

  1. レンタル取引は以下のフローで進行します。
    • 借り手が出品者に対してレンタル申請を行う
    • 出品者がレンタル申請を承認または拒否する
    • 承認後、借り手が決済を完了し取引が開始される
    • 出品者が商品を発送し、追跡番号を登録する
    • 借り手が商品を受け取り、受取確認を行う
    • レンタル期間終了後、借り手が商品を返送する
    • 出品者が返送商品を受け取り、取引が完了する
  2. 出品者は、合理的な理由なくレンタル申請を拒否し続けることはできません。
  3. 取引開始後のキャンセルについては、所定のキャンセルポリシーに従うものとします。

第7条（返品・返金）

  1. 借り手は、以下の場合に限り返品を申請できます。
    • 商品が出品情報と著しく異なる場合
    • 商品に重大な欠陥がある場合
    • 誤った商品が届いた場合
  2. 返品申請は、商品受取後48時間以内に行うものとします。
  3. 出品者は返品申請に対して承認または拒否を行います。双方の合意が得られない場合は、運営者が仲裁を行います。
  4. 返品が承認された場合、借り手に対してレンタル料金の返金処理が行われます。返金の方法および時期は運営者が定めるところによります。

第8条（支払い・決済）

  1. レンタル料金の支払いは、本サービスに登録されたクレジットカードを通じて行われます。
  2. 出品者は、レンタル料金を受け取るために銀行口座を登録する必要があります。
  3. 運営者は、取引完了時にレンタル料金の20%をサービス手数料として差し引き、残りの80%を出品者に振り込むものとします。
  4. 決済に関するトラブルについて、運営者は善意をもって対応しますが、最終的な解決を保証するものではありません。
  5. 借り手による商品の盗難・持ち逃げ等が発生した場合、運営者は調査・確認を行った上で、出品者に対しレンタル料金の全額（手数料差引前）および商品の時価相当額を補償するものとします。

第9条（配送）

  1. 出品者は、取引開始後速やかに商品を発送し、追跡番号を本サービス上に登録するものとします。
  2. 商品の梱包は出品者の責任において適切に行うものとし、配送中の破損について出品者が責任を負います。
  3. 配送の遅延が発生した場合、出品者は速やかに借り手に連絡するものとします。
  4. 返却時の配送費用は、特段の取り決めがない限り借り手が負担するものとします。

第10条（補償保険制度）

  1. 本サービスでは、レンタル中の商品に対する補償保険制度を提供しています。
  2. ユーザーは任意で補償保険に加入することができ、所定の保険料を支払うことで補償の対象となります。
  3. 補償の範囲は、レンタル期間中における商品の破損、故障、盗難等とします。ただし、以下の場合は補償の対象外とします。
    • 故意または重過失による損害
    • 通常の使用による経年劣化
    • 自然災害による損害
    • 補償保険に加入していない場合
  4. 補償請求は、事故発生後7日以内に所定の手続きにより行うものとします。
  5. 補償金額の上限および免責金額は、別途定めるところによります。
  6. 前各項に定める任意加入の補償保険とは別に、すべての取引にはプラットフォーム標準の盗難補償が適用されます。借り手による商品の盗難・持ち逃げ等が発生した場合、運営者は出品者に対しレンタル料金の全額（手数料差引前）および商品の時価相当額を補償します。
  7. 前項の補償の原資は、第8条第3項に定めるサービス手数料（レンタル料金の20%）によるものとします。

第11条（メッセージ機能）

  1. ユーザーは、商品に関する問い合わせや取引に関する連絡に本サービスのメッセージ機能を利用できます。
  2. メッセージ機能の利用にあたり、以下の行為を禁止します。
    • 個人情報（電話番号、住所等）の不必要な共有
    • 外部サービスへの誘導
    • 誹謗中傷、脅迫、嫌がらせ
    • 広告・宣伝目的のメッセージ送信
  3. 運営者は、不正行為の防止およびサービス改善のため、メッセージの内容を確認する場合があります。

第12条（レビュー・評価）

  1. 取引完了後、借り手および出品者は互いにレビューおよび評価を投稿できます。
  2. レビューは事実に基づき、公正かつ誠実に記載するものとします。
  3. 以下の内容を含むレビューは、運営者の判断により削除される場合があります。
    • 虚偽の内容
    • 誹謗中傷、差別的表現
    • 個人情報の記載
    • 取引と無関係な内容

第13条（ユーザー間の関係）

  1. ユーザーは、他のユーザーをフォローすることで、そのユーザーの出品情報等を受け取ることができます。
  2. ユーザーは、他のユーザーをブロックすることができます。ブロックされたユーザーからの連絡やレンタル申請は制限されます。
  3. 本規約に違反する行為を発見した場合、ユーザーは通報機能を通じて運営者に報告することができます。
  4. 運営者は通報内容を確認し、必要に応じて適切な措置を講じるものとします。

第14条（禁止事項）

ユーザーは、本サービスの利用にあたり、以下の行為を行ってはなりません。

  1. 法令または公序良俗に違反する行為
  2. 犯罪行為に関連する行為
  3. 他のユーザーまたは第三者の権利を侵害する行為
  4. 本サービスの運営を妨害する行為
  5. 不正アクセスまたはこれを試みる行為
  6. 他のユーザーに対するハラスメント、嫌がらせ、脅迫
  7. 本サービスを介さない直接取引（外部取引）の勧誘
  8. 虚偽の情報を登録・掲載する行為
  9. 複数アカウントの作成・運用
  10. 本サービスのシステムを不正に操作する行為
  11. その他、運営者が不適切と判断する行為

第15条（知的財産権）

  1. 本サービスに関するすべての知的財産権（商標、ロゴ、デザイン、ソフトウェア等）は運営者に帰属します。
  2. ユーザーが本サービス上にアップロードしたコンテンツ（商品画像、説明文、レビュー等）の著作権はユーザーに帰属しますが、ユーザーは運営者に対し、本サービスの運営に必要な範囲で当該コンテンツを使用する権利を無償で許諾するものとします。
  3. ユーザーは、第三者の知的財産権を侵害するコンテンツをアップロードしてはなりません。

第16条（免責事項）

  1. 運営者は、ユーザー間の取引の仲介者としてプラットフォームを提供するものであり、取引の当事者となるものではありません。
  2. 運営者は、出品された商品の品質、安全性、適法性、正確性等について保証するものではありません。
  3. ユーザー間のトラブルについては、原則としてユーザー間で解決するものとし、運営者は善意をもって仲裁に努めますが、解決を保証するものではありません。
  4. 本サービスの利用に起因してユーザーに生じた損害について、運営者の故意または重過失による場合を除き、運営者は責任を負わないものとします。

第17条（サービスの変更・停止）

  1. 運営者は、事前の通知なく本サービスの内容を変更し、または提供を停止することができるものとします。ただし、重要な変更については事前にユーザーに通知するよう努めます。
  2. 運営者は、以下の場合にユーザーのアカウントを停止または削除できるものとします。
    • 本規約に違反した場合
    • 登録情報に虚偽が判明した場合
    • 一定期間以上のログインがない場合
    • その他、運営者がアカウントの継続を適当でないと判断した場合
  3. システムメンテナンスや不可抗力によるサービス停止について、運営者は責任を負わないものとします。

第18条（その他）

  1. 本規約の準拠法は日本法とします。
  2. 本規約に関する紛争については、東京地方裁判所を第一審の専属的合意管轄裁判所とします。
  3. 運営者は、必要に応じて本規約を改定することができます。改定後の規約は、本サービス上に掲示された時点で効力を生じるものとします。
  4. 重要な改定を行う場合は、改定内容を事前に通知するものとします。改定後も本サービスの利用を継続した場合、ユーザーは改定後の規約に同意したものとみなします。
